# 書かれたものを生きる

## LIVING THE WRITTEN ── 時間・因果・自由・記憶・物語・虚構・持続の哲学、全8回

**すべてが決まっていたとしても、すべてはまだ生きられていない。**

未来が決まっていないから生きる意味があると、私たちは考えている。もし未来がすべて決まっているとしたら、現在を生きることにどのような意味があるのか。この連載は、テッド・チャン『あなたの人生の物語』の未来を記憶する言語学者から出発し、『進撃の巨人』の因果ループ、『たゆたいエマノン』の時間を跳ぶ少女、『ストロボライト』の書く者と書かれる者、『シン・エヴァンゲリオン劇場版』と『わかめとなみとむげんのものがたり』の虚構の登場人物、池永康晟の百夜の制作を順にたどり、**結末を知っていても、その結末に至る行為は省略できない**という見方へ至る。各回は独立した読み物であり、末尾の一行が次回へつながる。

[第1回から読む](chapters/01-perception-of-time.md) ／ [最終回を読む](chapters/08-living-the-written.md) ／ [読み方](guides/READING.md)

## 連載の構成

第I部（1〜3回）は時間と因果と自由を扱う。出来事を順番に知る認識と全体を一つの構造として把握する認識を区別し、結果を含む全体の条件から出来事を記述する見方を物理学と物語の両方で確かめ、未来を知ることとその未来を自分の行為で実現することの違いを示す。第II部（4〜5回）は記憶と物語を扱う。同じ時間を共有しない二人の関係と、現在の語りが過去の意味と過去の自己を成立させる構造を見る。第III部（6〜8回）は虚構と持続と存在を扱う。自分が虚構だと知った登場人物、描き続ける時間と完成による喪失を経て、確定した人生もなお未完了のまま生きられるという結論へ束ねる。

## ブラウザで読む（GitHub Pages）

`main` ブランチへのpushで `.github/workflows/pages.yml` が `_site/` を生成し、GitHub Pagesへ配置する。有効にするにはリポジトリの Settings → Pages → Build and deployment で Source を **GitHub Actions** にする。手順の詳細は[公開手順](guides/PUBLISHING.md)にある。

ローカルで再生成するにはPython 3.11以降とPandoc 3.xを使う。依存パッケージの追加インストールは不要である。

```sh
python scripts/validate.py
python scripts/build.py
python -m unittest discover -s tests -v
```

`_site/index.html` が目次付きの閲覧ページ、`_site/complete.html` が全8回とSVGを一つにまとめた単独ファイルである。GitHub管理対象はMarkdownとSVGなどの原本であり、`_site/` は生成物として `.gitignore` で除外する。

## 連載の成り立ちと編集

本文は、時間と物語をめぐる論考を、読者に読ませる随想として書き直したものである。各回は「冒頭の語り手の場面 → 作品の場面と概念の交互の配置 → 到達する主張 → 作品の情景で止まる結末」という型で書かれ、「逐次的認識と同時的認識」「知ることと生きることの違い」「結末を知っていても行為は省略できない」という論点が回をまたいで反復し、最終回で統合される。文体の規則は[文体ルール](guides/STYLE.md)に、原本と生成物の責務は[編集ガイド](guides/EDITING.md)に、表示環境の注意は[読み方](guides/READING.md)にまとめた。
