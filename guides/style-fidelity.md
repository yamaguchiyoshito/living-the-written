# 作品への忠実さ

随想寄りに書き直しても、作品と哲学的概念についての記述は事実の範囲を出ない。創作してよいのは語り手の場面だけである。

## 創作してよいもの、してはいけないもの

| 区分 | 扱い |
| --- | --- |
| 語り手「私」の状況、情景、感覚（冒頭と結末のみ） | 創作してよい |
| 作品に描かれた出来事、台詞、順序、結末 | 作品にあるものだけ。変えない、補わない |
| 作品に描かれていない場面、登場人物の内面、台詞 | 事実として書かない。書く場合は「〜と読める」「〜のように見える」など、解釈と分かる形にする |
| 哲学者の概念と主張（ベルクソン、クリステヴァ、フェルマーの原理など） | 原典や定評ある解説の範囲で述べる。筆者の展開は、哲学者の主張と区別する |
| 引用 | 文言を確認できる短いものに限る。要約した台詞を引用符で囲まない |

- 語り手の場面を、作品や哲学者の事実の裏付けとして使わない。「私がそう感じたから、ルイーズもそうだった」という接続をしない。
- 語り手の場面と作品の場面を、読者が取り違えない書き方にする。語り手の場面は「私」を主語に、作品の場面は登場人物を主語にする。

## 作品の叙述

- 登場人物を主語にして直接叙述する。「この作品では〜が描かれる」「物語の終盤で〜という場面がある」のような、作品を主語にした紹介文は、章に1回までとする。
- 例：×「『ストロボライト』では、現在の自分が過去を語ることで過去の自分が成立する構造が描かれる。」→○「現在の浜崎正が書くことで、二十歳の浜崎正が物語の中に立ち上がる。」
- 作品の順序を変えない。時間を圧縮して述べてよいが、出来事の前後と因果は作品のとおりにする。
- 登場人物を「情熱的」「孤独」などの形容で説明せず、作品の中で何をしたか、何を続けたか、何を知ったかで示す。
- 作品の場面を命題に還元しない。「可能性が無数に存在することは、自由が無数に存在することを意味しない」のような主張を置く前に、その主張を生む場面を、登場人物の行為として描く。
- 複数の作品を比較するとき、比較のために一方の作品の内容を単純化しない。対比が成り立たない点は、成り立たないと書くか、比較しない。

## 哲学的概念の叙述

- 概念は、提唱者の主張の範囲で述べる。筆者が概念を作品に適用して得た結論を、提唱者の主張として書かない。
- 例：×「ベルクソンによれば、完成は喪失である。」→○「ベルクソンは持続を、分割できない流れとして捉えた。この見方を制作に当てはめると、完成は〜」
- 物理学の原理（フェルマーの原理、変分原理）は、物理学として正しい範囲で述べ、比喩として使う箇所では比喩であることを文の形で示す。
- 「未来の条件で現象を記述できること」と「未来が過去に影響すること」のような、現行の記事が区別している論点は、改稿で崩さない。

## 引用

- 作品からの引用は短く、文言を確認したものに限る。訳書を使う場合は訳者を注に記す。
- 哲学書からの引用も同様とする。孫引きは、孫引きであると注に記す。
- 引用の出典は、本文の後の注にまとめる。本文に「〜によれば」「〜（p.〜）」を入れない。
- 引用文の文言は、原文で確認したものを第一とする。原文が手元にない場合は、出版社や公式サイトの紹介文、Wikipedia の引用、新聞・雑誌の記事など、Web上で文言を確認できるものに限って使い、確認したURLと取得日、原文で未照合であることを脚注に記す。複数の非公式サイトで文言が一致するだけのものは、台詞の短い引用に限って使い、同じく未照合と記す。記憶で補わない。巻・話・章が分からない箇所には入れない。
- 1か所の引用は1〜3文、数十字までとする。本文の議論が主で引用が従になる分量に抑え、引用の直前か直後の段落がその文言を受けて言い換えるか解釈していることを条件にする。引用だけを置いて次の話題に移らない。
- 1文以内の短い引用は「」で地の文に入れる。2文以上は引用段落（行頭の `>`）にし、段落の前後を空ける。引用段落の直後に出典の脚注 `[^id]` を付け、脚注の定義にページまで書く。
- 引用の文言は変えない。省略は「（中略）」で示し、強調を足さない。漢字と仮名の表記も原文のとおりにする。
- 台詞を引く場合、誰の台詞かを本文の側で示す。作品の筋を変える順序で引用を並べない。
- 引用文は各権利者に帰属し、本リポジトリのライセンス（CC BY 4.0）の対象外である。README にその旨を記す。

## 禁止

- 作品の結末、台詞、出来事を、書きやすさのために変えること。
- 作品にない場面を、語り手の体験として書いて、作品の場面に見せること。
- 哲学者の名前を、筆者の主張の権威づけに使うこと。
- 本文に、参照の経路を語る文言（「原作では」「Wikipediaによれば」「解説書にはそうある」）を入れること。
