# 文体ルール（連載「書かれたものを生きる」改稿用）

chapters/ の全8回を、読者に読ませる文体へ改稿するための規則群。論旨と中心の問いは変えず、息の長さと読者への指示の多さを直す。

## 決定事項

| 論点 | 決定 |
| --- | --- |
| 文体の寄せ先 | 随想モード寄り。常体は維持する |
| 語り手 | 「私」の具体的な場面は冒頭と結末にだけ許す。本論は「私たち」のまま |
| 想定読者と媒体 | SFや漫画は読むが哲学書は読まない一般読者。note かブログ |
| 連載装置 | 「前回は」の段落は削除。「本回のインサイト」は削除。「次回」は区切り線の下に1行 |
| 太字と見出し | 太字は1回あたり最大2個。見出しは番号とラベルを外し、5〜8に減らす |
| 段落と文 | 1段落3〜6文。読点と「しかし」を減らす。短文の連打をやめる |
| 分量 | 縮小を許す。数値目標は置かず、1本試作してから決める |
| 置き場所 | guides/ に分割。SKILL.md は本文改稿に入る段階で書く |

## ファイル

| ファイル | 内容 |
| --- | --- |
| [style-rhythm.md](style-rhythm.md) | 段落の束ね方、読点、文の長短、文末と文頭、接続詞 |
| [structure.md](style-structure.md) | 冒頭、本論、見出し、結末、連載装置、題名 |
| [fidelity.md](style-fidelity.md) | 作品と哲学的概念への忠実さ、語り手の場面の扱い、引用 |
| [readers.md](style-readers.md) | 想定読者、用語の説明、ネタバレ、読者への指示の禁止 |
| [checklist.md](style-checklist.md) | 改稿の手順と、完成前の確認項目 |

## 適用の順序

1. [structure.md](style-structure.md) で骨格を決める。見出しを減らし、連載装置を外し、冒頭と結末を決める。
2. [style-rhythm.md](style-rhythm.md) で段落を束ね、文を整える。
3. [fidelity.md](style-fidelity.md) と [readers.md](style-readers.md) で、作品の記述と用語の説明を点検する。
4. [checklist.md](style-checklist.md) で確認し、音読して直す。

## 変えないもの

- 常体。「である」調を「ですます」に変えない。
- 各回の中心の問いと、結末で到達する主張。
- 作品の選択と、作品相互の対比の構図。
- 作品名の『 』表記。
