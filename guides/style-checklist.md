# 改稿チェックリスト

1本を改稿するときの手順と、完成前の確認項目。数値はすべて目安であり、意味が壊れる場合は意味を優先する。

## 手順

1. 現行の記事を通読し、中心の問いと、結末で到達する主張を1行ずつ書き出す。改稿後もこの2行が本文に残るようにする。
2. 見出しを5〜8に統合する。番号とラベルを外す（[structure.md](style-structure.md)）。
3. 「前回は」の段落、「本回のインサイト」ブロック、複数段落の次回予告を外す。次回は区切り線の下に1行で残す。
4. 冒頭を書き直す。作品名と人名を出さず、具体的な場面か短い一文から入る。語り手「私」の場面を使う場合はここに置く。
5. 結末を書き直す。「結論」の章を廃し、最後の一文を作品の情景か未完の状態で止める。
6. 本論の段落を3〜6文に束ねる。言い換えの重複を減らす（[style-rhythm.md](style-rhythm.md)）。
7. 読点、文末、文頭、接続詞を整える。`python3 -I scripts/check_rhythm.py chapters/NN-xxx.md` で、章ごとの段落数、疑問文、「しかし」、短文と長文の有無、読点の過多、同じ文末と主語始まりの連続を確認する。
8. 太字を最大2個に減らす。
9. 作品の場面が命題に還元されている箇所を、登場人物を主語にした叙述に戻す（[fidelity.md](style-fidelity.md)）。
10. 用語の初出を確認し、定義文より先に具体例を置く（[readers.md](style-readers.md)）。
11. 全文を音読する気持ちで読み、つかえる箇所を直す。
12. 区切り線の下に、作品と参照文献の注を付ける。

## 数値の目安

| 項目 | 目安 |
| --- | --- |
| 冒頭の「私」の場面 | 1段落、120字前後 |
| 冒頭の太字の問いまで | 250字以内 |
| 章見出し | 5〜8 |
| 1段落の文数 | 3〜6 |
| 一文だけの段落 | 1章に1つまで |
| 読点 | 40字以内の文で0〜1個、長文で2個まで |
| 読点のない文 | 段落の半数以上 |
| 同じ文末の連続 | 2回まで |
| 主語始まりの連続 | 3文まで |
| 「しかし」 | 1章に2回まで |
| 段落先頭の「つまり」「したがって」「そして」「ここで」 | 1章に合わせて3回まで |
| 疑問文 | 1章に1回まで、全体で5回以内 |
| 太字 | 1回あたり最大2個 |

| 新しい用語 | 1章に2つまで |
| 作品を主語にした紹介文 | 1章に1回まで |

## 完成前の確認

- 冒頭の第1段落から最初の見出しまでに、作品名、人名、哲学者名がない。
- 最後の一文が、作品の情景、行為、未完の状態、沈黙のどれかで止まっている。
- 最後の一文が、語り手の体験、教訓、総括、対比のまとめで閉じていない。
- 「本回のインサイト」「前回は」「結論：」「逆説：」「隠された含意：」が残っていない。
- 中心の問いと、到達する主張が、本文に残っている。
- 作品の出来事、順序、結末が、作品のとおりである。
- 語り手の場面が、作品の場面と取り違えられない。
- 哲学者の主張と、筆者の展開が区別されている。
- 「重要なのは」「ここで注意すべきは」「あまりにも当たり前」のような、読み方を指定する一文がない。
- 読者の感情を指定する形容がない。
- 本文に箇条書き、表、出典の説明がない。
- 単体で読んで、前回の内容を知らなくても筋が追える。

## 試作

- 最初の1本は第1回で試す。最も短く、作品が1つで、冒頭の型と結末の型が全回に共通するため、ここで決めた形を他の回に展開しやすい。
- 試作後に、字数の変化と、読みやすさの変化を確認し、分量の目安をこの文書に追記する。

## 試作の結果（第1回、2026-10-29）

- 字数は空白を除いて 6,852 字から 5,616 字になった（約82%）。段落の統合と言い換えの削除だけでこの程度縮む。他の回も、現状の8割前後を目安にしてよい。
- 見出しは12から8（副題を含む）になった。段落は218から37、一文だけの段落は1（太字の問い）になった。
- 疑問文は4、太字は2、「しかし」は0、作品を主語にした紹介文は各章1以下に収まった。
- 守りにくかった目安は「中間の長さ（25〜45字）が4文続かない」で、8章中6章で一度ずつ残った。意味を変えずに直せない箇所は残してよい。
- 一文だけの段落には「読点のない文が半数以上」の目安を当てない。

## 全8回の結果（2026-10-29）

第1回の試作と同じ手順で第2〜8回も改稿し、全8回を chapters/ に置き換えた（元の版は保持していない）。字数（空白除く）は元記事比で 69〜87% に収まり、見出しは第7回の9本を除いて副題込み8本、太字は各回2個、疑問文は各回2〜5回、「しかし」は0、検査スクリプトの警告は全回0になった。分量の目安は「元記事の7〜8割」に改める。一文だけの段落が多く言い換えの重複が多い回ほど縮みが大きい。
