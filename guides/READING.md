# 読み方と表示環境

[連載目次へ](../README.md)

## GitHubのMarkdownで読む

リポジトリのREADMEから各回を開き、Preview表示を使う。RawやCode表示は原稿テキストを見るためのものであり、図は表示されない。各回の冒頭と末尾に、前回・目次・次回のリンクがある。

## HTMLで読む

GitHub Pagesが有効なら、公開URLのトップページが目次になる。手元で再生成した場合は `_site/index.html` をブラウザで開く。サーバー起動は不要である。全8回を一つのファイルで読む場合は `_site/complete.html` を開く。どちらも外部通信をしない。

## 再生成する

Python 3.11以降とPandoc 3.xを使う。Python標準ライブラリだけを使うため、pipによる追加導入は不要である。Pandocの導入方法は[公式インストール案内](https://pandoc.org/installing.html)を参照する。

```sh
python --version
pandoc --version
python scripts/validate.py
python scripts/build.py
```

WindowsでPythonコマンドが `py` の場合は `py -3 scripts/build.py` とする。HTMLを作る前にMarkdownの検査を行い、警告を残したまま公開しない。

## 表示の設計

本文は1行がおよそ45字になる幅（720px）、16px、行間1.8で組んである。段落は3〜6文を基本とし、太字は各回の中心の問いと到達する主張の2文に限っている。節見出しは太字のみで、縦線や下線は引用や表との区別のために使わない。各回の冒頭と末尾にある枠つきの行が前後の回へのリンクで、末尾には次回の題名を添えている。図は本文幅に収め、細い枠で本文と区別する。電話幅では図を横にスクロールでき、タップすると原寸のSVGが開く。

## 図と注の読み分け

挿絵は原典の転載ではなく、本連載の説明のために作成した概念図である。図は本文で説明し終えた段落の直後に置き、各回の冒頭と結末の語り手の場面には置いていない。矢印は必ずしも因果を表さない。キャプションに示す前提を併せて読む。

脚注の出典は、扱った作品と参照した理論の書誌であり、原文の引用ではない。作品の出来事、順序、結末は作品のとおりに述べ、作品に描かれていない場面や台詞を補っていない。各回の冒頭と結末にある語り手「私」の場面は創作であり、作品の事実とは区別している。哲学者の主張（ベルクソンの持続、クリステヴァの間テクスト性、オースティンの遂行的発話）と本連載の展開は、本文と注で区別している。「逐次的認識」「同時的認識」は本連載の用語である。
