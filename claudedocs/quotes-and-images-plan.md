# 引用文と作品画像の計画（2026-10-29）

本文に、扱った作品の引用文と画像を、その段落の議論に結びつく形で入れるための計画。実施結果は末尾の「実施記録」にある。

## 前提

- **引用文は原文の文言をそのまま使う。** 私の手元に作品の本文はないので、文言、巻・章・ページ、訳者は、本を持つ筆者が確認して提供する。Web上の転記は誤りが多く、照合の補助にしか使わない。要約を引用符で囲まない規則（guides/style-fidelity.md）はそのまま適用する。
- **引用は短く、必要な箇所に限る。** 1か所は1〜3文、数十字まで。本文の議論が主で引用が従になる分量に抑え、引用の直前か直後の段落がその文言を必要としていること（本文で言い換えや解釈が続くこと）を条件にする。
- **画像は作品の著作物である。** リポジトリは CC BY 4.0 だが、引用した文言と画像は各権利者に帰属し CC BY の対象外であると README と LICENSE の脇に明記する。画像は引用の要件（必要最小限、本文が主で画像が従、出典の明記、改変しない）を満たす範囲に限る。
- **技術面。** 画像は `assets/works/` に jpg か png で置く（外部参照は検査で禁止されている）。検査スクリプトは SVG の枚数だけを数えるので、作品画像は挿絵の番号に影響しない。キャプションは「図N-k」ではなく「書影：」「場面：」で始め、出典は脚注に書く。

## 画像の選択肢

| 案 | 内容 | 利点 | 懸念 |
| --- | --- | --- | --- |
| A 書影 | 各作品の表紙を1点ずつ、初出の節に置く（8作品＋TENETは任意） | 慣行として広く行われ、本文との関連が明確。入手しやすい | 表紙も著作物であり、権利者の意向で削除を求められうる |
| B 場面 | 本文が論じる特定の場面（『進撃の巨人』121話のコマ、『ストロボライト』のコマ、『わかめとなみ』終章のコマ、映画の一場面）を必要最小限で引用 | 本文の議論と画像が直接結びつく | 引用の要件の判断が厳しく、画集の絵（池永）は画家の権利が強い。コマの切り出しは改変と見なされる余地がある |
| C なし | 画像は現在の概念図のみ。引用文だけを足す | 権利の懸念がない | 作品の手触りは文章だけになる |

推奨は **A（書影）＋引用文**。B は『進撃の巨人』121話の1コマと『ストロボライト』の1コマに限って検討し、池永康晟の絵と映画の場面写真は使わない。

## 作業の順序（決定後）

1. 規則を足す。guides/style-fidelity.md に引用文の条件（短さ、原文確認、脚注の形式、本文との主従）を、guides/EDITING.md に作品画像の置き方（`assets/works/`、キャプションの形式、出典の脚注、権利の注記）を追記する。README と LICENSE の脇に、引用文と画像が CC BY の対象外であることを明記する。
2. 筆者が、候補表の各箇所について原文の文言、巻・章・ページ、訳者を確認して提供する。提供のない箇所は入れない。
3. 引用文を本文に入れる。短いものは「」で地の文に、2文以上は引用段落（`>`）にする。出典は `[^id]` の脚注に、ページまで書く。`references/sources.json` の `checked` を「原文で照合済み」に更新する。
4. 画像を `assets/works/` に置き、初出の節に「書影：」のキャプションと脚注を付ける。横幅は本文幅に収め、ファイルは1点200KB以下にする。
5. 検査、試験、ビルド、HTML検査を通し、ブラウザで確認して push する。

## 決めてほしいこと

1. 画像の範囲（A、B、C のどれか。B なら対象のコマ）。
2. 引用文の原文の提供方法（候補表の箇所について筆者が文言とページを書き出すか、本の該当ページの写真を送るか）。
3. 引用の数（初回は12か所前後に絞る案でよいか）。
